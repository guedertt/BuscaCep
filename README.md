Título:
Busca de CEP

Descrição curta:
Aplicação web simples que busca endereço a partir de um CEP utilizando a API pública ViaCEP (fetch).

Funcionalidade:

Entrada de CEP

Validação de CEP

Exibição de logradouro, bairro, cidade e estado
Implementa lógica de consulta de API com JavaScript. 
iMasters

Tecnologias:
HTML, CSS, JavaScript, Fetch API, ViaCEP API

Como rodar:

clonar o repo

abrir index.html no navegador
