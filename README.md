# Busca de CEP

Aplicação web simples que busca informações de endereço a partir de um CEP, utilizando a API pública **ViaCEP**.

## Funcionalidades
- Entrada de CEP  
- Validação de CEP  
- Exibição de:
  - Logradouro  
  - Bairro  
  - Cidade  
  - Estado  

O projeto implementa a lógica de consumo de API utilizando **JavaScript (Fetch API)**.

## Tecnologias
- HTML  
- CSS  
- JavaScript  
- Fetch API  
- ViaCEP API  

## Como rodar o projeto
1. Clone o repositório  
2. Abra o arquivo `index.html` no navegador  

## Objetivo
Projeto desenvolvido para praticar consumo de API, manipulação do DOM e fundamentos de desenvolvimento web.
